Como funciona

O cliente monta o carrinho e finaliza a compra. O Mercado Express grava o pedido como PENDENTE, reserva o estoque e publica a solicitação na exchange mercado.pagamentos.exchange. Um consumidor chama a API do Banco Tranquilo, publica a resposta e, se o pagamento for aprovado, o cliente recebe um e-mail de confirmação, registrado na tabela emails_enviados.

Fluxo de mensagens

POST /api/compras └─▶ pagamento.solicitado ──▶ Banco Tranquilo (:8081) └─▶ pagamento.resultado ──▶ pedido CONFIRMADO / CANCELADO └─▶ email.confirmacao ──▶ SMTP + emails_enviados
